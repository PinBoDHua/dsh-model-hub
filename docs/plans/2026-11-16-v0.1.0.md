# dsh-model-hub v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在官方 `dsh-llm-pi-ai` 适配器之上做一个百炼模型接入管理层：实测模型库 + 一键智能合并应用 + 运行时复验 + 发现兜底，让官方模型选择器显示 16 个可用模型与推理强度行。

**Architecture:** cordis bundle（host 插件 + web client）。host 经 `ctx.configEditor.edit()` 把经实测的百炼目录智能合并进 profile 的 `llm-pi-ai` 条目（只动 aliyun provider，保留用户自加模型，复用 `ALIYUN_API_KEY`）；client 经官方 `settings.models.footer` / `settings.models.provider-card` slot 嵌入 Models 页，经 `conversation.input.model.label` slot 给选择器注入徽标。数据面走 `ctx.webServer` 命名路由 `/plugins/dsh-model-hub/*`（进程 token + 回环，与 dsh-memory 同模式）。不 import 任何 `@deepseek-ai/*`（本地链接 ESM 够不到安装树），服务经 `ctx.get/inject` 取。

**Tech Stack:** Node ≥22.6 ESM（host，无构建）；classic-script client（`window.__ModuleLoader__.load`，React 来自浏览器模块表，无构建）；`node --test` 单测；真实宿主集成测试参照 dsh-smart-router。

**Spec:** 本会话 grill-me 共识（8 项决策），见 `docs/DESIGN-CONSENSUS.md`。

## Global Constraints

- 插件名 `dsh-model-hub`；version `0.1.0`；`engines.dsh >=0.2.0-rc.2`、`node >=22.6`。
- cordis.patch.yml 必须 `insert` 形式（裸 `- id:` 是覆盖写法，id 不存在会被跳过）。
- host 不 import `@deepseek-ai/*`；服务经 `ctx.get(name)` / `ctx.inject([names], cb)`。
- 只修改 `llm-pi-ai` 条目的 `providers.aliyun`；绝不删除用户模型；绝不改全局默认模型（除非用户点"设为默认"）。
- 凭据复用 `ALIYUN_API_KEY`（harness 凭据 seam）；插件不自存密钥；探针/日志永不输出密钥值。
- 探针请求 `max_tokens<=64`、带超时、失败关闭（不硬发）。
- client 文案走 `ctx.locale`（zh/en）；跟随宿主主题（`--dsw-alias-*` 令牌 + `body[data-ds-dark-theme]`）；slot 组件非交互内联（label slot）。
- 不主动 git commit（用户未要求）；git 仅用于跟踪。
- 过滤非对话模型：`wan*`、`qwen-audio*`、`qwen-image*`。

- [ ] **Step 1: lib/apply.js**：
```js
export async function applySelection(ctx, { modelIds }, catalog, defaults) {
  const editor = ctx.get('configEditor')
  const entries = editor.entries()
  const entry = entries.find(e => e.id === 'llm-pi-ai' || e.name === '@deepseek-ai/dsh-llm-pi-ai')
  if (!entry) throw Object.assign(new Error('llm-pi-ai adapter not mounted'),{code:'no-adapter'})
  const selected = catalog.models.filter(m => modelIds.includes(m.id))
  await editor.edit(entry, (current) => {
    const next = structuredClone(current ?? {})
    next.providers ??= {}
    const cur = next.providers[defaults.providerId] ?? {}
    next.providers[defaults.providerId] = buildProviderConfig(cur, selected, defaults)
    return next
  })
  return { applied: selected.length, providerId: defaults.providerId }
}
```
