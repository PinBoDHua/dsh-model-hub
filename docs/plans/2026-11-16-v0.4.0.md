## 步骤

1. **lib/providers.js**：16 平台注册表（id/displayName{zh,en}/kind/api/baseURL/apiKeyEnv/probe/discover/probeBaseURL?/routeApi?/nonChat?/preset）。纯数据 + resolveProviders(config) 合并用户覆盖。
2. **lib/catalog.js**：loadCatalog 兼容新元数据；presetsDir 枚举；逐平台加载。
3. **lib/protocols.js**：probeFor(protocol)/discoverFor(protocol) 分发；openai-responses/anthropic-messages/google-generative-ai 方言（fetchImpl 可注入）；deriveModel 保持 completions 语义；probeMaxOutput 协议门禁。probe.js 保留为 completions 方言实现（现有单测不动）。
4. **lib/discover.js**：nonChat 过滤参数化（默认百炼正则）；overlayCandidates 不变。
5. **lib/merge.js**：stripEntryFor(kind, m)——custom 全字段；catalog 薄写入 {id,name}+manualFields。buildProviderConfig 增 routeApi 默认（仅 undefined 时写）。
6. **lib/edit.js**：applyEdit 追踪 manualFields（draft 出现的字段累积）。
7. **lib/validate.js**：validateDraft(draft, protocol='openai-completions') compat 门禁。
8. **lib/service.js**：catalogs Map 懒加载 + catalogs/<id>.json 持久化 + 旧 catalog.json 迁移；全部操作 provider 参数化；status 追加 providers 数组；verify 分层（custom 派生双写 / catalog 仅 evidence）；discover 按平台方言。
9. **lib/routes.js**：GET /providers；catalog/status 读 query.provider；写操作读 body.provider；其余不变。
10. **index.js**：不变（config 解析扩展在 config.js）。
11. **scripts/gen-presets.mjs + presets/*.json**：从 pi-ai 目录数据生成 12 个目录路由 preset（精选 + recommended 标记 + 展示快照）；手写 zhipu/siliconflow/volcengine preset（文档基线）；bailian.json 不动。
12. **client/client.js**：平台 Select + 逐平台状态 + provider-card 泛化 + ModelLabel 索引缓存徽标 + EditorForm 协议感知 + locale（title 改「模型库」等）+ 纯逻辑 UMD 导出（providerOptions 等）。
13. **tests**：新增 providers/protocols/multi-service/routes-provider/presets-schema/client-options 单测；dsh.test 增目录路由薄写入 schema 证据 + 阴性对照；version 断言 0.4.0。
14. **package.json**：version 0.4.0、description/keywords 多平台、exports presets/*.json、scripts.gen-presets。
15. **验证**：npm run verify 全绿 → plugin_manager remove→install → 回环 live-check（status/providers/catalog?provider=…/aliyun 单模型复验）→ GUI 实测（平台切换/徽标/百炼不回退）→ 截图存档。
16. **文档收尾**：CHANGELOG 0.4.0、README 重写、VERIFICATION-v0.4.0.md。

## 风险与对策

- 目录路由薄写入过不了官方 schema → test:dsh 用真实 Config 校验（决定性），先跑通再接 UI。
- 旧 runtime catalog.json 迁移丢数据 → 迁移保留原件；迁移失败回退直读旧文件。
- 平台切换竞态（fetch 乱序）→ 请求序号守卫，仅采纳最新平台的结果。
- openrouter route api 重指用户自加 anthropic 原生模型 → 文档明示；merge 不删用户模型。
