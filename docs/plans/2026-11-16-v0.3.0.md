# dsh-model-hub v0.3.0 Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. 按任务顺序实施，每任务带验证口径。

**Goal:** 下拉体验对齐 dsh-memory——5 处原生 `<select>` 全部替换为统一自定义无障碍 `Select`（button + portal listbox），彻底主题化、完整键盘/ARIA；顺带修复 locale meta 格式。

**Architecture:** 继承 v0.2 cordis bundle，host 侧零改动（除 locale 资源与版本号）。client factory 内移植 dsh-memory 的 Select 组件（行为等价拷贝 + dm→mh 改名）+ 最小图标字典；选项构造抽为纯逻辑 UMD 导出供 node 单测。

**Tech Stack:** Node ESM host（无构建）+ classic-script client（宿主 React/ReactDOM）；node --test；Edge headless + CDP GUI 自动化。

**Spec:** docs/DESIGN-CONSENSUS-v0.3.0.md（十二项决策）。

## Global Constraints
- 无缝兼容：筛选值/草稿保持内存态；路由/payload/catalog 结构不动；devRole 三值语义不变。
- 零跨插件依赖；不 require 宿主组件包；令牌只用已核实定义的 --dsw-alias-* 名。
- 不动官方 composer 选择器、ModelLabel/ProviderCard 既有逻辑、面板其余 CSS。
- 不主动 git commit；不发 npm。
- 实施前基线备份：_scratch/model-hub-v0.2.0-backup/（Time Machine 快照因工作区过大超时，改用定向备份）。
