# dsh-model-hub v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理深度——面板逐模型编辑（全字段+结构化compat）、证据查看、重置目录、max-output 实测；目录+配置双写+失败回滚。

**Architecture:** 继承 v0.1 cordis bundle。新增 lib/validate.js（纯校验）、lib/edit.js（applyEdit 纯合并）；probe.js 增 probeMaxOutput；service 增 editModel/measureMaxOutput + commitEdit 双写回滚；routes 增 edit/reset/measure-max-output；client 卡片内联编辑器+重置确认。

**Tech Stack:** Node ESM host（无构建）+ classic-script client；node --test；官方适配器 Config schema 集成校验。

**Spec:** docs/DESIGN-CONSENSUS-v0.2.0.md（九项决策）。

## Global Constraints
- 继承 v0.1 不变量：不删用户模型/保留 provider 用户字段/复用 ALIYUN_API_KEY/不改全局默认/探针极小+超时+失败关闭+不输出密钥/只动 aliyun。
- 双写：编辑先改目录；已应用模型同步 configEditor；config 失败回滚目录。未应用只改目录。
- 重置回 shipped preset、二次确认、不动 live。
- capacitySource 标记 context/maxOutput 来源（estimate/manual/measured）；不写入适配器配置。
- compat 控件仅三键；validate 镜像适配器 schema 约束。
- 不主动 git commit。
